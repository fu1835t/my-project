# 《磚塊勇者：元素秘境》（Brick Hero: Elemental Realms）

這是一款結合經典打磚塊玩法與冒險 RPG 元素的網頁動作遊戲。玩家將操縱勇者戰艦之板，穿梭於三大元素秘境，突破多種特殊機制磚塊，迎戰各具獨特攻擊彈幕與技能的主題 Boss。

---

## 關卡秘境與機制設計

### 1. 翡翠森林（Emerald Forest）
- **環境特色**：綠意盎然的林地，帶有飄落樹葉粒子。
- **特殊磚塊**：
  - **蔓藤磚（Vine Brick）**：若未被徹底摧毀，具備自我癒合再生的特性。
  - **毒孢磚（Spore Brick）**：擊破時釋放毒孢迷霧，使板子移動速度減半數秒。
  - **枯木硬磚（Armored Brick）**：需要多次撞擊才能瓦解。
- **世界霸主**：**遠古守護者「綠茵巨靈」（Ancient Treant）**
  - 投擲分裂堅果彈攻擊板子。
  - 召喚蔓藤屏障阻擋彈珠路徑。

### 2. 灼熱沙漠（Sunken Desert）
- **環境特色**：黃沙飛揚的荒漠遺蹟，帶有狂風粒子。
- **特殊磚塊**：
  - **流沙磚（Quicksand Brick）**：磚體會隨時間緩慢水平漂移，干擾彈道預測。
  - **TNT 炸藥磚（Bomb Brick）**：被擊破時引發 3x3 區域劇烈殉爆，清空周圍磚塊。
  - **砂岩重磚**：具備高硬度的多層磚塊。
- **世界霸主**：**黃沙霸權「法老巨像」（Pharaoh Colossus）**
  - 鎖定勇者之板當前位置，發動全螢幕貫穿的「烈日裁決」雷射天罰。
  - 射出灼熱烈日導引能量彈。

### 3. 蒼藍深淵（Abyssal Ocean）
- **環境特色**：暗潮湧動的水底世界，帶有上升水泡微粒。
- **特殊磚塊**：
  - **氣泡護盾磚（Bubble Brick）**：包裹著水流護盾，需先擊破氣泡才能傷害本體。
  - **冰晶霜磚（Ice Brick）**：破碎時釋放急凍霜波，連帶摧毀緊鄰的磚塊。
- **世界霸主**：**深淵霸主「克拉肯巨獸」（Abyssal Kraken）**
  - 散射高密度深海暗黑水彈。
  - 釋放深海暗黑渦流與震盪波。

## 勇者之板與冒險技能

玩家接球或破壞磚塊可積累魔力值（MP），用於施放強大的主動冒險技能：

- **[Q] 聖光護盾（Aegis Shield）**：消耗 30 MP。在遊戲底線生成一道持續 12 秒的能量防護網，可完全抵擋一次漏球失誤。
- **[W] 烈焰貫穿（Fireball Blast）**：消耗 40 MP。使場上所有彈珠燃燒烈焰，持續 7 秒內直接貫穿普通磚塊而不發生反彈。
- **[E] 雷霆雙極（Thunder Strike）**：消耗 50 MP。自板子兩側垂直發射貫穿天際的雷電光束，瞬間蒸發路徑上的所有磚塊並對 Boss 造成巨幅傷害。

---

## 冒險者營地與升級系統

在順利通關每一小節或擊破世界 Boss 後，將進入「冒險者營地」，可消耗冒險中收集的金幣進行各項永久性強化：

- **神聖體質（Max HP）**：增加板子的生命值上限與當前生命。
- **板體加寬（Paddle Width）**：擴展勇者之板的長度，提升接球容錯率。
- **破壞重擊（Ball Damage）**：提升彈珠基礎撞擊力，對硬磚與 Boss 造成更高傷害。
- **魔力湧流（Mana Regen）**：提升每秒被動回魔速率，讓技能施放更頻繁。
- **極速吟唱（Skill Haste）**：縮短所有主動技能的冷卻時間。

## 操作說明

- **板子移動**：滑鼠水平移動 或 使用鍵盤方向鍵 `Left` / `Right`、`A` / `D`
- **彈珠發射**：滑鼠左鍵 或 鍵盤 `Space`（空白鍵）
- **技能施放**：鍵盤 `Q`、`W`、`E`（亦可直接點擊畫面下方技能圖示）
- **音效切換**：點擊右上角「音效開 / 靜音中」按鈕

## 啟動與執行方式

本專案採用純前端技術（HTML5 Canvas + Web Audio API + 模組化原生 JavaScript）開發，無需安裝額外依賴套件，支援離線執行：

1. **直接開啟**：在檔案總管中雙擊 `index.html` 或執行 `run_game.bat` 即可直接在瀏覽器中暢玩。
2. **本機伺服器**（可選）：
   ```powershell
   python -m http.server 8000
   ```
   接著在瀏覽器打開 `http://localhost:8000` 即可。
